Sayfa Editörü

⚠ GITHUB_TOKEN gerekli

Sayfa editörü çalışmak için GitHub Personal Access Token gerektirir.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained
  2. Repository: ozgunustuay-sirius/bysirius.com
  3. Permission: Contents → Read & Write
  4. Token'ı kopyalayın
  5. Vercel dashboard → her iki proje → Environment Variables → GITHUB_TOKEN ekle
  6. Redeploy yapın
✓ Kaydedildiğinde GitHub'a commit atılır → Vercel otomatik yeniden deploy eder (~30 saniye).
